# Internal audit of the 1.0 review set (20 Nov 2026)

The audit Codex was to do, done in-house because Codex was unavailable. Five reviewers worked in parallel, one per
slice:

- ctm-checkers;
- ctm-libs with pyodide-interaktiv;
- math-exercise, py-exercise and ctm-demo;
- ctm-stack;
- the umbrella.

Each was given the code and the finding it claims to fix, not the author's conclusions. Each worked on its own
worktrees, ran the suites on base and head, and tried to break the changes. Every finding below was then
re-checked, the confirmed ones fixed on the same review branches, and each fix tested.

Reviewed heads: ctm-assessment `ef41196`, ctm-checkers `ac5fd12`, ctm-libs `bed034c`, math-exercise `844f2c2`,
py-exercise `62661b5`, ctm-stack `9f872e4`, pyodide-interaktiv `d7fe10a`, ctm-demo `2f5fb2d`.

**Disposition:**
- **fixed**: on the review branch, with a test that fails without the fix where one is practical;
- **documented**: the behaviour stays, the docs now say so;
- **recorded**: open, accepted for 1.0 or left to AC.

## Verified as claimed

- **ctm-checkers:**
  - the wheels match `src/`;
  - 9,500/9,500 golden rows reproduce (src and wheel);
  - the new tests fail without their fixes;
  - no learner-only bypass was found through Unicode identifiers, `split_symbols`, implicit application or allow-listed SymPy classes once C-1 was fixed.
- **ctm-libs:**
  - the stream caps, timers and cancellation;
  - provider formats: `include_usage`, `finish_reason: null`, reasoning deltas, CRLF, split events;
  - all components go through `ctm.feedback.enabled()`;
  - the correction path (N-1) has no defect;
  - locales are complete.
- **pyodide-interaktiv:**
  - the copy equals ctm-libs `bed034c` byte for byte;
  - 135/135 tests pass;
  - the worker changes since `793a872` (WebKit stop probe, interrupt buffer) need AC's P13 re-approval, as the runbook says.
- **math-exercise:**
  - Lua and JS names are identical in en, nb and de;
  - `field-labels` are escaped;
  - no unnamed textbox remains on the example site;
  - Enter and click races give one check;
  - restore needs no Python.
- **ctm-stack:**
  - settings precedence;
  - no silent fallback to SymPy;
  - staging rejects tampered records, archives, traversal, links, devices and wrong STACK sources;
  - `_ctm-stack-native/` is neither rendered nor copied;
  - the parity numbers reproduce exactly (full rerun).
- **Umbrella:**
  - response framing of 301, 304, 416, HEAD and errors;
  - the asset rule with encoded segments;
  - the JSXGraph trees are identical;
  - the ZIP and deployment checks run before publishing;
  - nothing consumes the removed alias, `--refresh` or the deleted workflow;
  - the review trailer parses and names the branch heads;
  - every SHA in the release records exists.
