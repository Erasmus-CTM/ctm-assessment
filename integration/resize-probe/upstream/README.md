# Source phase candidate — diagnostic only

Quarto's BODY geometry read runs inside its leading ResizeObserver callback. An earlier exact failure records the BODY callback/error at 403/409 ms, before Monaco callbacks at 1060 ms. The later full interaction matrix also requires Monaco's callback to be deferred: Quarto alone still fails during later interactions. These are two rendering-phase hazards, not evidence that removing a component is acceptable.

The rendering model recalculates layout between ResizeObserver broadcasts and permits only increasingly deep targets in one delivery cycle. Reading and then changing layout at the already-delivered BODY depth can leave a shallow observation undelivered. The patches move layout work into the next animation-frame phase, before the next observation cycle. They do not change the observer constructor globally, remove observations, substitute content-box width, suppress errors, or add a time-based startup delay.

## Canonical source and patch pair

- `quarto-phase.patch`: `quarto-dev/quarto-cli` tag `v1.10.19`, `src/resources/formats/html/quarto.js`, original Git blob `ee807684be1ca09f37f5a711051ecf3bec8f0906`. Quarto 1.8.27's actual frozen fixture has the identical callback span. Its full browser source SHA256 is `14589dacd0cf625c4e6891269681a0a8e20aaa5390864ca6a69f2fff1514719a`.
- `monaco-phase.patch`: canonical VS Code commit `31c37ee8f63491495ac49e43b8544550fbae4533`, `src/vs/editor/browser/config/elementSizeObserver.ts`, Git blob `33eefc3aba8612430c2ffb46212aa173629ce454`. Monaco's `v0.46.0/package.json` declares this exact `vscodeRef`. The licensed `elementSizeObserver.ts` copy is test input only. The published 0.46.0 AMD file SHA256 is `6902b6112c4235349088a6cb86e3d95cd9b3fab7710cc38f681f8af5c9ad99ae`.

Quarto retains its 50 ms throttle, the exact transformed BODY border-box predicate, width-first localStorage short circuit, margin layout and reader toggle. Only admitted layout work moves one frame. Monaco coalesces notifications into one pending frame, uses the latest copied dimensions, and checks observer identity before applying a queued layout after stop/restart. It does no idle polling. Its canonical source and AMD adapter are exercised with the same first/latest/stop behavior tests.

The exact browser experiment uses matched real HTTP fixture copies under `require-corp`, preserving all enhancements. The three Monaco CDN roots are rebased identically to the exact public 0.46.0 package, with the original/changed main-script hashes guarded. This avoids response interception. Native positive controls must reproduce in WebKit. Raw errors remain assertions and report data. Controls cover reader desktop/390px/transformed BODY, synthetic margin collision and a real reader control, editor edit/resize/tab round trips, and storage denied after startup on a wide page.

This is a candidate upstream patch pair, not a production fix or release acceptance. Both canonical publishers need an approved version/build path, followed by fresh combined strict store/course gates. Quarto current main also synchronizes scrollable regions in this callback: any main-targeted port must place that work inside the same frame and retain trailing throttle semantics. Current Monaco canonical source still has a leading-immediate path; a version bump cannot be assumed to solve it. AC owns upstream contact and merges.
