Worker.terminate() vs. a WebAssembly loop

Each button starts workers that enter a loop, then calls worker.terminate() after 300 ms. Watch the CPU use of the tab's web content process (Activity Monitor: "localhost" / "Safari Web Content", or top -o cpu). Expected: back to ~0% at once. WebKit: each terminated worker of the first two kinds keeps one core at 100% until the tab's process exits; reloading the page does not help.
